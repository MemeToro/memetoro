# Security Policy

MemeToro is experimental, unaudited, and not ready to manage real funds. No production smart contracts have been implemented.

## Reporting a vulnerability

Do not post a security issue publicly if it could put funds, credentials, infrastructure, or users at risk.

An official private disclosure channel will be added here before any testnet or production deployment. Until then, avoid sharing exploitable details in public issues; provide only enough information to indicate that a private contact method is needed.

Never send private keys, seed phrases, or other credentials with a report.
