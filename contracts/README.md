# MemeToro Contracts

MemeToro plans to use public smart contracts to apply each proposal's published launch rules deterministically. The contracts are intended to:

- Accept contributions in the declared funding asset.
- Enforce per-wallet contribution caps.
- Enforce funding thresholds and deadlines.
- Prevent launch terms from changing after funding begins.
- Allow anyone to finalize a launch when its conditions are met.
- Allow participants to claim tokens or request refunds without relying on the backend.
- Ensure that no token allocation goes to developers, administrators, or other insiders.

No Solidity contracts have been implemented yet. Nothing in this directory is audited or ready for production use.
